Production RAG Service — Layer-by-Layer Flow

FastAPI · OpenAI (gpt-6-luna answers, text-embedding-3-small) · LangChain · Qdrant · SQLite · pypdf / python-docx (+ B5 types). Mirrors PLAN.md, which is the source of truth. B# = optional bonus feature (JWT auth is B1; with AUTH_ENABLED=false the same flow runs with a fixed default owner and no token).
