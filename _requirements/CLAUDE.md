# Project instructions for Claude Code

## Git and GitHub attribution

- Never add Claude as an author, co-author or contributor to anything pushed to git or GitHub.
- Do not add a `Co-Authored-By: Claude ...` trailer (or any similar trailer) to commit messages.
- Do not add "Generated with Claude Code", a Claude session link or any other AI attribution line to commit messages, pull request titles, pull request descriptions, issues or comments.
- Do not change the git author or committer name or email. Commits must use the user's own git config.
- If a tool, template or default setting would add Claude attribution, remove it before committing or pushing.
